# صدرافارس — سامانه محاسبه تعرفه‌های مهندسی ساختمان

*[English version](README.md)*

یک اپلیکیشن تحت وب تخصصی که تعرفه‌های رسمی نظام مهندسی ساختمان ایران — نقشه‌برداری، نظارت، و طراحی — رو محاسبه می‌کنه؛ شامل نرخ‌های منطقه‌ای و جریمه‌ی تأخیر.

## مسئله

جدول تعرفه‌ی نظام مهندسی ساختمان ایران واقعاً پیچیده‌ست: نرخ‌ها بر اساس سال، رشته (عمران، معماری، تاسیسات مکانیکی/برقی)، پایه‌ی نظارت (A تا D، هرکدوم با ضرایب تفکیک متفاوت)، و منطقه تغییر می‌کنن. مهندسان این محاسبات رو دستی و از روی جداول منتشرشده انجام می‌دادن — کند و مستعد خطا، مخصوصاً برای موارد تمدید نظارت که نیاز به تقسیم یک مبلغ کل بین چند رشته با ضرایب مخصوص هر پایه داره.

## راه‌حل

یک اپلیکیشن FastAPI + رندر سمت سرور (Jinja) که کل جدول تعرفه‌ی رسمی رو به‌جای جدول‌های ثابت، به‌صورت قوانین قابل‌اجرا پیاده‌سازی می‌کنه: مساحی زمین (پلکانی بر اساس متراژ)، حق‌الزحمه‌ی طراحی و نظارت مهندسی، تفکیک ضرایب بین رشته‌ها برای تمدید نظارت، و محاسبه‌ی جریمه‌ی تأخیر — همراه با یک نقشه‌ی مبتنی‌بر Leaflet برای انتخاب منطقه/محدوده، به‌علاوه‌ی حساب‌های کاربری با احراز هویت برای ذخیره و مرور دوباره‌ی محاسبات.

## ویژگی‌های کلیدی

- چند محاسبه‌گر تعرفه: مساحی زمین، طراحی/نظارت مهندسی، تمدید نظارت (با تفکیک ضریب به تفکیک رشته و پایه)، و جریمه‌ی تأخیر
- انتخاب منطقه/محدوده از طریق نقشه‌ی تعاملی، که نرخ‌های مخصوص همون موقعیت رو تغذیه می‌کنه
- حساب کاربری (ثبت‌نام/ورود) با داشبورد شخصی برای محاسبات قبلی
- صفحات رندرشده در سمت سرور (سریع، سازگار با SEO، بدون نیاز به فریم‌ورک سنگین سمت کلاینت برای این نوع ابزار)

## پشته‌ی فنی

- **پایتون**، FastAPI، قالب‌های Jinja2 رندرشده در سرور
- **Leaflet** برای نقشه‌ی تعاملی محدوده‌ها
- **Tailwind CSS** برای پایپ‌لاین بیلد فرانت‌اند
- مسیرهای API محافظت‌شده با احراز هویت، در کنار مسیرهای صفحات

## وضعیت

اپلیکیشن زنده و دیپلوی‌شده — برای یک مخاطب حرفه‌ای مشخص (مهندسان دارای پروانه‌ی نظام مهندسی ساختمان) با جداول تعرفه‌ی رسمی و منتشرشده به‌عنوان منبع اصلی صحت داده ساخته شده.
